📰 新闻数据分析项目（News Data Analysis）

## 📌 项目简介

本项目基于 Python 对新闻数据进行清洗、分析与可视化，旨在挖掘新闻文本中的信息分布特征和时间趋势。

通过本项目，我系统练习了数据处理流程，并为后续自然语言处理（NLP）和大模型应用（如 RAG）打下基础。

---

## 🚀 项目功能

* 📂 数据读取（CSV / JSON）
* 🧹 数据清洗（缺失值处理、去重）
* 🧠 文本处理（分词、词频统计）
* 📊 数据分析：

  * 新闻类别分布
  * 高频词统计
  * 发布时间趋势分析
* 📈 数据可视化（柱状图 / 折线图）

---

## 🛠️ 技术栈

* Python
* pandas
* numpy
* matplotlib
* （可选）jieba（中文分词）
